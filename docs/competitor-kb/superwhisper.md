# Superwhisper

> Maker of a Mac/Windows/iOS Whisper-based dictation app for professionals; ultra-fast AI dictation that turns speech into "perfect emails, crisp notes, clear messages" via a two-stage voice-transcription + AI-cleanup pipeline (superwhisper.com/docs/get-started/introduction). One of the closest technical relatives of Nasar Flow.

## Facts
- **Maker / founded / funding:** Maker entity not disclosed on any crawled page; enterprise contact is enterprise@superwhisper.com, support is support@superwhisper.com, security/trust hosted on a third-party Trust Center at trust.mycroft.io/superwhisper (superwhisper.com/docs/security/compliance).
- **Platforms:** macOS 13.3+, Windows 10/11 (x64 + ARM64, several features still catching up to Mac), iOS 18+ (iPhone/iPad). No Android. (superwhisper.com/download, superwhisper.com/docs/get-started/windows)
- **Pricing:** Free tier, no expiry (Standard/Nano/Fast Whisper models, limited cloud voice). Pro: $8.49/mo, $84.99/yr (~17% off monthly), or $249.99 lifetime — one license covers unlimited Macs, unlimited Windows PCs, and personal iPhone/iPad. Free Pro trial raised from 15 minutes to 3,000 words (Aug 26 2026, v2.18.2). 30-day refund window. Separate "Superwhisper Enterprise" org tier with seat-based billing. (superwhisper.com/docs/get-started/sw-pro, superwhisper.com/changelog, superwhisper.com/docs/enterprise/getting-started)
- **Engine:** Two independently-configurable pipeline stages — (1) a **voice/transcription model** (cloud or local Whisper-family, Parakeet, Nova, Cohere, or Superwhisper's own S1-Voice) and (2) an optional **language/cleanup model** ("AI Processing" — cloud LLMs from Anthropic/OpenAI/Groq/Superwhisper, or local LLMs on macOS only). Can run fully local (local voice model + local LLM, macOS only; Windows has no local-LLM cleanup, so it falls back to transcription-only "Voice to Text"). (superwhisper.com/docs/security/sensitive-data, superwhisper.com/docs/models/language)
- **Languages:** 100+ claimed, auto-detect on most models; translate-to-English toggle on Whisper-family/S1-Voice; Nova and Parakeet do **not** support multiple languages within one dictation session. (superwhisper.com/docs/models/voice, superwhisper.com/docs/common-issues/language-detection)

## Activation & capture UX
- Menu-bar app, color-coded status dot: **yellow** = model loading, **red** = recording, **blue** = processing, **green** = complete. Same dot repeats in the recording window's Status Indicator (minus red — recording state shown via the window itself). (superwhisper.com/docs/get-started/interface-menu-bar, /interface-rec-window)
- Menu-bar click behavior: default click opens the full menu; "Quick Recording Mode" (an advanced setting) makes left-click toggle recording directly and right-click open the menu. (interface-menu-bar)
- **Keyboard Shortcuts** (Settings → Keyboard Shortcuts tab), all independently rebindable, no fixed factory-default combo published in docs:
  - **Toggle Recording** — start/stop; single modifier keys alone (Left ⌘, Right ⌘, Fn) are valid bindings.
  - **Push-to-Talk** — press-and-hold to record, release to stop; can share the same physical key as Toggle Recording.
  - **Cancel Recording** — instant if the recording is under 30s; shows a confirmation prompt if longer (anti-accidental-cancel); during the post-recording *processing* stage the cancel shortcut only hides the window, it doesn't stop processing.
  - **Change Mode** — hold modifier + tap assigned key to cycle modes, before or during dictation.
  - **Mouse Shortcut** — bind a mouse button: quick click = toggle, press-and-hold = push-to-talk (hardware-dependent; some mice can't detect holds). (superwhisper.com/docs/get-started/settings-shortcuts)
- Recording window has two forms: full window and **Mini Recording Window** (compact); either can be set to always show or fully hidden (audio-cue-only). Full window components: Resize Toggle, Audio Waveform (static waveform with moving audio = healthy mic; a static waveform during Custom-mode system-audio capture is expected/benign), Status Indicator dot, Mode Display (click to switch modes; shows live app/site context in Super Mode), Context Capture indicator (lights up when clipboard/selected-text context was captured), Stop button, Cancel button. Mini window supports hover controls (Change Mode / Start Recording / Expand) and right-click menu (Expand / Open Settings / Open History). (superwhisper.com/docs/get-started/interface-rec-window)
- Audio cues (start/complete sounds) fire even with the visual recording window fully disabled. "Auto-Close Window" closes the window post-dictation regardless of paste success. (settings-advanced)
- iOS activation: from Mac, scan a QR code shown in Mac Settings; from Windows (no QR support), enter the license via a `superwhisper://license/YOUR-KEY` deep link in Safari or directly in the iOS app's Settings. (superwhisper.com/docs/get-started/activate-ios)
- **iOS 26.4 keyboard-extension regression** (documented candidly): Apple removed the ability for third-party keyboards to programmatically return the user to the previous app after the keyboard's dictation button is tapped — users must now swipe back manually. Superwhisper filed Apple Feedback ID **FB22247647** (bug in `hostApplicationBundleID`) and publicly encourages users to also file feedback to pressure Apple. All modes still work; only the auto-return behavior broke. (superwhisper.com/docs/common-issues/ios-26-keyboard-changes) — directly relevant: Nasar Flow's own keyboard extension will hit the same iOS platform constraint.

## Text insertion
- Default mechanism is **clipboard copy + simulated paste** at the cursor — described by Superwhisper's own accessibility page as sitting "next to" screen readers (VoiceOver/NVDA) rather than replacing them, i.e., it is not writing via the OS accessibility tree.
- **"Restore Clipboard"** — restores the user's prior clipboard contents after the paste-insert completes; default flipped to **on** as of Sept 3 2026 (v2.18.3). (changelog, settings-advanced)
- **"Simulate Keypresses"** — experimental fallback that types the result via simulated keystrokes instead of copy/paste, for apps/fields that block programmatic paste; explicitly documented as **US QWERTY layout only**, and **not yet supported on Windows** at all. (settings-advanced, superwhisper.com/docs/get-started/windows)
- **"Hold Shift to Auto-Send"** — holding Shift while ending dictation simulates pressing Return/Enter, for chat-send convenience; **not yet supported on Windows**. (settings-advanced, /windows)
- Fallback behavior: if both the recording window and "Paste Result Text" are disabled, the result still lands on the clipboard for manual paste — insertion never silently fails to produce something retrievable.
- No named list of "known-broken apps" was published; Troubleshooting instead generically covers recording/shortcut conflicts, audio capture, transcription/AI failures, context-awareness failures, and Realtime availability. (superwhisper.com/docs/common-issues/troubleshooting)

## Accuracy & personalization
- **Full voice/transcription model matrix** (superwhisper.com/docs/models/voice — speed and accuracy given as the site's own 0-10 relative scale, not absolute benchmarks, except where WER % is separately published):
  - **S1-Voice (Cloud)** — Superwhisper's own model; multi-language, translation supported; speed 10, accuracy 9; Pro. Cross-referenced WER on the blog: 6.6% average error rate, ~26x realtime.
  - **Ultra (Cloud)** — Superwhisper cloud; multi-language, translation; speed 9, accuracy 9; Pro; ~10.6% WER, ~24x.
  - **Ultra V3 Turbo** (local, OpenAI Whisper) — all languages, translation; speed 8, accuracy 8; 1.6 GB; Pro; ~10.9% WER, ~9.4x. Chinese-only variant "Ultra V3 Turbo (Chinese)" trades multilingual for speed at the same accuracy tier.
  - **Ultra** (local, OpenAI Whisper) — all languages, translation; speed 6, accuracy 10 (Superwhisper's own highest-accuracy local rating); 3.0 GB; Pro; ~13.0% WER.
  - **Pro** / **Pro (English)** (local, OpenAI Whisper) — speed 7, accuracy 8; 1.5 GB; Pro; ~15.8% WER; English-only SKU drops translation+multilingual for a smaller prompt surface.
  - **Standard** / **Standard (English)** (local, OpenAI Whisper, **free tier**) — speed 8, accuracy 5; 500 MB; ~15.6% WER.
  - **Nano** / **Nano (English)** (local, free) — speed 9, accuracy 3; 150 MB.
  - **Fast** / **Fast (English)** (local, free, fastest) — speed 10, accuracy 1 (lowest); 75 MB; ~20.3% WER.
  - **Parakeet** / **Parakeet Multilanguage** (local, NVIDIA) — English-only vs. multilingual SKU; speed 10 (fastest local, ~118-133x realtime), accuracy 8; 476-494 MB; Pro; ~10.4-10.7% WER; **no translation, no multi-language-within-session support** (see Languages section).
  - **Cohere Transcribe** (local) — 1.3 GB; ~8.4% WER, ~24x; Pro; gained auto language detection Aug 4 2026.
  - **Nova 3 / Nova 2 / Nova Medical** (cloud, Deepgram) — multi-language, no translation; speed 7, accuracy 8/7; Pro; Nova 3 ~10.1% WER, ~23x; Nova Medical tuned for English medical terminology; Nova models are the **only** ones supporting Realtime/streaming (see Languages section) and speaker-separated meetings.
- **Full language/cleanup model matrix** (superwhisper.com/docs/models/language — "Benchmark" is the site's own 0-100 quality score, "Speed" its own 0-10 scale):
  - **S1-Language (Cloud)** — Superwhisper's own; speed 10, benchmark ~80; Pro.
  - **Anthropic (Cloud)**: Claude 4.5 Sonnet (speed 8, benchmark 89), Claude 4 Sonnet (8, 87), Claude 3.7 Sonnet (8, 85), Claude 3.5 Sonnet (8, 89), Claude 3.5 Haiku (9, 75) — all Pro.
  - **OpenAI (Cloud)**: GPT-5 (7, 91), GPT-5 mini (8, 87), GPT-5 nano (9, 83), GPT-4.1 (7, 90), GPT-4.1 mini (8, 86), GPT-4.1 nano (9, 80) — all Pro.
  - **Groq (Cloud, LPU inference)**: Llama 3 8B (speed 10, benchmark 67) — Pro.
  - **Local (macOS only)**: GPT OSS 20B, DeepSeek R1 Distill, Ministral 3 8B, Llama 3 8B, Mistral 7B v0.2, Llama 3.2 3B, Phi-2 3B, plus the proprietary **S1-mini** (see Formatting section) — all Pro-gated despite running fully offline.
- **Vocabulary**: free-text list of custom words/acronyms/names/foreign terms sent as a recognition-hint prompt to the transcription model. Explicit warning: "Adding too many words can confuse the AI transcription model" and can degrade punctuation, language detection, and formatting — keep the list short and essential. (superwhisper.com/docs/get-started/interface-vocabulary, /hallucinations)
- **Replacements**: deterministic, non-AI, post-transcription find/replace. Case-insensitive matching, output cased exactly as defined; **whole-word only** ("'Cat' will be replaced with 'Dog', but 'Caterpillar' will not become Dogerpillar"). Used for symbol/spelling expansion (`at sign`→`@`, `dot com`→`.com`, `slash`→`/`) and canned strings (e.g. a saved work email address). Shares one UI with Vocabulary; delete via a trash-can icon per row. (interface-vocabulary)
- **Language-detection quirk & fix**: on the "Automatic" language setting, non-English speech is sometimes mis-transcribed as English because the transcription prompt can't predict which language(s) will be spoken. Documented workaround: add a **sentence written in the target language** to Vocabulary (e.g., a Spanish speaker adds "y también puede incluir palabras en español") — this "vocabulary hint" trick works on all voice models **except Nova and Parakeet**, since those two don't support multi-language switching within one session at all. Alternative: build separate language-specific Modes, or add "preserve the input language" instructions to a Custom Mode prompt. (superwhisper.com/docs/common-issues/language-detection) — this is the single most relevant "gotcha" in the whole crawl for a Singlish/Malay/Arabic app: Superwhisper's mainline models are documented as NOT reliably supporting intra-session multi-language switching without a manual prompt-injection workaround.
- **Context Awareness** (Super Mode / Custom Modes), explicitly built on **accessibility APIs** per superwhisper.com/docs/modes/super: (1) **Application Context** — active app name + text from the focused input field/editor, captured after transcription (between transcription and AI steps); when active it also silently includes system date/time, the user's full name, and computer name, "to help the AI handle things like inserting the date, signing off an email with your name"; (2) **Selected Text Context** — whatever's highlighted in the frontmost app at the exact moment recording starts; (3) **Clipboard Context** — content copied within ~3s before recording, or at any point during dictation (last-copied item wins). Docs warn enabling unneeded context "can send excessive information to the AI, potentially affecting result quality," and separately warn it's also a hallucination source (see below). (superwhisper.com/docs/modes/super, /docs/common-issues/context, /hallucinations)
- Super Mode is the only *built-in* mode with all three context types on by default; Custom Modes can mix any combination. (super, modes)
- **File transcription**: accepts MP3, MP4, mono 16kHz WAV via menu bar, Finder "Open With," or CLI; applies the currently-active mode's formatting to the output — so file transcription and live dictation share the exact same formatting/AI pipeline, not a separate code path. (superwhisper.com/docs/get-started/transcribe-files)
- **Speaker-separated meetings**: Nova cloud models support speaker identification/diarization, combinable with AI post-processing for meeting summaries. (referenced in superwhisper.com/docs/llms.txt: /modes/speaker-separated-meetings)

## Formatting & AI cleanup
- **Modes** = named bundles of {voice model, AI/language model, AI instructions ("prompt"), context-awareness settings}. Built-ins: **Voice to Text** (transcription only, zero AI step — "speed-optimized... where AI processing is not required"), **Message**, **Email**, **Note**, **Meeting** (records + transcribes + summarizes with action items), **Super**. (superwhisper.com/docs/modes/modes, /message, /email, /note, /meeting)
- **Custom Mode** exposes the actual prompt-engineering surface to end users — this is Superwhisper's most technically transparent doc page. Confirmed context variable names a user can reference directly in their own AI instructions: `User Message` (the dictated text), `Application Context`, `Selected Text`, `Clipboard Context`. Documented example instructions: *"Translate the User Message to Spanish,"* *"Based on the Application Context, suggest relevant code comments,"* *"Format the User Message accordingly based on the content found in Clipboard Context."* Docs explicitly recommend telling the model the input is spoken: *"The User Message contains dictated text. Please format it into proper paragraphs."* XML-tag prompt structuring (`<role>`, `<instructions>`, `<requirements>`, `<context>`, `<style>`, `<output-format>`) is documented as optional but improves quality on "advanced models," while warning local/weaker models "may misinterpret or be confused by XML tags." Few-shot **Input/Output example pairs** (2–3 recommended) can be attached per mode via an "Add Example" UI. Instructions are **empty by default** on a fresh Custom Mode — "AI will not know what task to perform and may give unexpected results" if left blank. (superwhisper.com/docs/modes/custom)
- **Customizing a built-in mode**: there's no direct "duplicate & edit" button — the documented workflow is to run a test dictation through the built-in mode, open the History tab, copy the exact system prompt text Superwhisper sent to the AI for that mode (visible in the History "prompt" sidebar), paste it into a new Custom Mode, and edit from there. Built-in mode prompts are unpublished elsewhere but are fully inspectable this way. (superwhisper.com/docs/modes/customizing-modes)
- **S1-mini** (proprietary on-device cleanup LLM, 484 MB / 0.6B params, zero network calls): automatic formatting (lists, emails, spacing), filler-word/stutter removal, number/date/currency/URL normalization, and **Tone control** across 5 levels — casual, semi-casual, balanced, semi-formal, formal — shipped for Message/Mail/Notes apps specifically (Aug 17 2026, v2.17.3). Explicit non-goals stated by the team: S1-mini "will never add content you did not say, correct facts, soften profanity, flag what you are talking about, or rewrite your dialect." (superwhisper.com/blog/s1) — the "rewrite your dialect" non-goal is the single most on-point competitive data point for Nasar Flow: Superwhisper is already publicly promising not to normalize a user's own phrasing away, which is exactly the trust claim a Singlish/Malay app needs to make louder and more specifically.
- **Voice-to-Text mode** and any mode with no AI step never runs cleanup at all — a genuinely "raw" toggle exists, it's just mode selection rather than a per-dictation switch.
- **Silence Removal** ("Remove Silence," Sound tab) strips silent gaps from the audio *before* transcription; documented specifically as a fix for **transcription hallucinations** (a Whisper-family failure mode where silence causes invented words/sentences), turned on by default as of Sept 3 2026 (v2.18.3). (superwhisper.com/docs/common-issues/hallucinations, changelog)
- LLM-stage hallucinations (AI answering an unasked question, wrong formatting, invented content) are separately documented, attributed to: imprecise Custom Mode prompts, lack of few-shot examples, weaker/local models needing more explicit prompting, or over-included context (too much Application/Clipboard Context confusing the model). (superwhisper.com/docs/common-issues/hallucinations)

## Voice commands
- Not a general spoken command grammar — narrowly scoped to **Super Mode "Commands," which only operate on already-selected text**, and only for *formatting/transformation*, not content generation: documented **correct** examples — "Make this text title case," "Convert selection to uppercase," "Format my selected text as bullet points" — vs. documented **incorrect** examples that Super Mode is not meant to handle — "Summarize this paragraph," "Expand on these ideas," "Rewrite this section" (those need Custom Mode instead). Using selection/copy isn't required at all for normal dictation — it's optional. (superwhisper.com/docs/modes/super)
- No spoken commands for editing (no documented "delete that," "new line," "undo," "select X") — all recording/cancel/mode-switch control is keyboard- or mouse-based (see Activation section).
- Community layer fills some of this gap: **Superwhisper for Raycast** (start/stop, change modes, open settings), **Superwhisper for Alfred** (start/stop, switch modes, search/filter recording history from the search bar), **Macrowhisper** (watches the recordings folder and auto-runs "smart actions" — text insertion, opening links, shell scripts, macOS Shortcuts — when a dictation finishes), **Superwhisper Recording Analysis** (personal-analytics Python tool with AI-generated usage summaries). (superwhisper.com/docs/get-started/community)

## Languages & multilingual
- 100+ languages advertised, auto-detect on most models. (introduction)
- **Model SKUs bifurcate multilingual vs. English-only** for speed: e.g. Parakeet vs. Parakeet Multilanguage, Ultra V3 Turbo vs. Ultra V3 Turbo (Chinese), Pro vs. Pro (English), Standard vs. Standard (English), Nano/Fast likewise — the English-only variant is consistently faster/smaller for the same accuracy tier. (superwhisper.com/docs/models/voice)
- **Nova (Deepgram) and Parakeet (NVIDIA) explicitly do not support switching languages within a single dictation session** — confirmed directly in docs, not inferred. Whisper-family and S1-Voice do support it, and can be nudged toward reliably detecting a specific non-English language via the "vocabulary hint" trick (see Accuracy section above). (superwhisper.com/docs/common-issues/language-detection)
- "Translation" (speech → English text) is a togglable per-model capability on Whisper-family/S1-Voice models only, not on Parakeet or Nova. (superwhisper.com/docs/models/voice)
- Realtime/**streaming transcription is supported only on Deepgram Nova (Cloud) voice models** — everything else (Whisper family, Parakeet, S1-Voice, Cohere) is **batch**: audio is fully captured, then transcribed after recording stops. Enabling Realtime requires selecting a Nova model in a mode's Advanced Settings, after which a "Realtime" toggle becomes available. (superwhisper.com/docs/common-issues/realtime) — important VAD/streaming data point: on-device streaming ASR is *not* something Superwhisper ships at all; their only "watch words appear as you speak" experience is cloud-only.
- No marketing claim anywhere in the crawled docs about handling **two languages mixed within the same utterance/sentence** (true code-switching) — multilingual support here means session-level language selection/detection, not intra-sentence mixing.

## Privacy & data
- "Your data is not retained on Superwhisper servers. All data is only stored locally on your machine." Local models process audio entirely on-device. Cloud models (OpenAI, Anthropic, Deepgram, Groq, Cohere) are accessed under **zero-data-retention** API terms — "we do not collect any audio recordings, transcriptions, or personally identifiable information (PII)" server-side; content isn't used for provider model training. This covers Superwhisper's own API integration only, not e.g. a user manually pasting into a provider's website. (superwhisper.com/privacy, /docs/security/sensitive-data)
- **Compliance is more extensive than a first pass suggests**: Superwhisper states support for **HIPAA, GDPR, SOC 2** via a third-party-hosted Trust Center (trust.mycroft.io/superwhisper) offering SOC 2 report + pen-test reports under NDA, plus a self-serve DocuSeal flow to sign a **DPA** and, for healthcare, a **BAA**. Three documented HIPAA paths: (1) local-only models — no BAA needed, nothing leaves device; (2) Superwhisper cloud models — sign Superwhisper's BAA, upstream zero-retention applies; (3) BYOK — sign a BAA directly with the upstream provider (Anthropic/OpenAI etc.), Superwhisper is just a client. (superwhisper.com/docs/security/compliance)
- Local audio recordings are written to disk by default (per third-party audit, in the iCloud Documents folder) with no documented in-app encryption of that local history; a **scheduled auto-delete via cron job** is documented as the mitigation path (History Management doc, referenced in llms.txt) rather than an in-app toggle — corroborates third-party reviews describing this as a privacy gap for casual users. (getroutines.ai/transparency/superwhisper; superwhisper.com/docs/get-started/history-management per llms.txt)
- Enterprise: SAML SSO / Google OAuth / Magic Link, org-wide policy push, admin controls to disable cloud models or restrict to approved providers (Azure OpenAI, AWS Bedrock, self-hosted, Amazon Bedrock has a dedicated setup doc), silent deployment via Jamf/Intune/any MDM with pre-granted mic permission, centralized seat billing, and **optional, off-by-default, metadata-only Usage Analytics** with a stated "full transparency on what we collect and what we never collect." SCIM provisioning has its own dedicated doc (superwhisper.com/docs/enterprise/scim). (superwhisper.com/docs/enterprise/getting-started, /usage-analytics, /scim)

## Blog / engineering insights
- **"Introducing the S1 family of models"** (superwhisper.com/blog/s1): **S1-Voice** (cloud transcription) claims ~46× faster than real-time speech; most sub-30s dictations return within 0.32s of speech ending; 6.8% WER averaged across 8 diverse benchmark datasets, 2.2% WER on LibriSpeech, claimed to beat 14 other tested models. **S1-mini** (on-device cleanup, 484MB/0.6B params) reports 94.8% token accuracy and 11.6% text-edit error rate over 7,519 held-out test cases, and is explicitly scoped to formatting/cleanup only — not fact-correction, profanity-softening, content-flagging, or "rewriting your dialect." That non-goal is the standout engineering/trust claim relevant to Nasar Flow.
- No separate architecture/latency/eval blog posts beyond the S1 post surfaced in this crawl (superwhisper.com/blog likely has more not individually crawled here).
- The Custom Mode prompting docs (see Formatting section) function as a de facto engineering disclosure: exact context-variable names, an admission that local/weaker models "may misinterpret" XML-structured prompts, and a documented technique (copy the real prompt out of History) for reverse-engineering built-in mode prompts.

## User complaints (reviews, Reddit, HN, App Store)
- **Mobile app reliability**: iOS app described in review round-ups as "infuriating," with recording failures reported on 10+ minute dictations; iPhone experience called less polished than Mac. (spokenly.app/blog/superwhisper-review)
- **iOS 26.4 keyboard regression**: Superwhisper's own docs concede a real, user-visible regression — third-party keyboards on iOS can no longer auto-return the user to the calling app, requiring a manual swipe-back after every dictation; they've filed an Apple bug report and are asking users to pile on. (superwhisper.com/docs/common-issues/ios-26-keyboard-changes)
- **Windows feature gap**: FileSync, custom app-folder location, Hold-Shift-to-Auto-Send, Simulate Keypresses, and agentic coding integrations are all documented as **not yet available on Windows**, plus separate community reports of crashes and target-app freezes during paste/insertion. (superwhisper.com/docs/get-started/windows, feedback.superwhisper.com)
- **Privacy gaps in practice vs. marketing**: local audio saved to disk by default with no obvious in-app opt-out surfaced to casual (non-Enterprise) users, and cloud-model API keys reported stored in a plaintext config file rather than the OS keychain. (getroutines.ai/transparency/superwhisper)
- **Setup complexity**: reviewers compare first-run configuration to "configuring a server" given the size of the model/mode/settings surface. (max-productive.ai/ai-tools/superwhisper, spokenly.app/blog/superwhisper-review)
- **Accuracy edge cases**: proper nouns and numbers called out as unreliable in some reviews, with no fast in-app way to spot-check output against the source audio (though the History tab does expose raw transcription vs. AI output side-by-side, per the docs — reviewers may simply not know this).
- **Pricing friction**: the $249.99 lifetime tier is a specific point of debate in review headlines vs. subscription competitors like Wispr Flow. (spokenly.app/blog/superwhisper-review)
- Ratings are strong overall — ~4.4/5 on the Mac App Store (~800 ratings), 4.9/5 on Product Hunt (21 reviews) — so these are recurring minority complaints, not a rating crisis.

## Best-practice takeaways
1. **Decouple transcription (STT) and cleanup (LLM) into two independently-configurable pipeline stages**, each choosable local-or-cloud on its own axis (superwhisper.com/docs/security/sensitive-data). This makes privacy/cost/quality trade-offs legible and composable instead of one opaque "on-device mode" switch.
2. **Publish an explicit non-goals list for AI cleanup**, specifically naming dialect preservation: S1-mini "will never... rewrite your dialect" (superwhisper.com/blog/s1). This is a trust-building, quotable design constraint, not an internal implementation detail.
3. **Ship a genuinely inspectable prompt-engineering surface for power users**: named context variables (`User Message`, `Application Context`, `Selected Text`, `Clipboard Context`), documented XML-tag structuring with an honest caveat that weaker/local models handle it worse, and a working few-shot "Add Example" input/output UI (superwhisper.com/docs/modes/custom).
4. **Let users retrieve the exact system prompt used for any past dictation via a History tab**, and document how to copy a built-in mode's real prompt to bootstrap a custom one (superwhisper.com/docs/modes/customizing-modes) — turns "black box AI" into a debuggable, forkable artifact.
5. **Ship two SKUs of the same model — multilingual vs. single-language-optimized — and be explicit about which capabilities (translation, multi-language switching) each does and doesn't have** (superwhisper.com/docs/models/voice, /common-issues/language-detection), rather than a single "it just works" claim that breaks silently.
6. **Separate deterministic Replacements (whole-word, case-preserving, non-AI) from probabilistic Vocabulary hints**, and document the exact matching semantics (case-insensitive match, output-case-preserving, whole-word-only) so users can predict behavior (interface-vocabulary).
7. **Silence-based VAD tied explicitly to a named hallucination fix ("Remove Silence")**, not just a vague "quality" toggle — ship the causal story, not just the switch (common-issues/hallucinations).
8. **Publish a public Trust Center + self-serve DPA/BAA signing flow** even before every certification is "done," with a clear three-path HIPAA decision tree (local-only / cloud-with-Superwhisper's-BAA / BYOK-with-your-own-BAA) (superwhisper.com/docs/security/compliance).
9. **Publish a machine-readable llms.txt + per-page markdown twins.** Cheap, and it measurably improved how fast and precisely this exact competitive-research task could extract facts.
10. **Be candid about platform-vendor breakage** (the iOS 26.4 keyboard auto-return regression, with a named Apple Feedback bug ID) rather than silently absorbing the complaint — it converts a "the app is broken" review into a "we found the Apple bug and reported it" trust signal.

## Ideas Nasar Flow should steal or beat
1. **[beat] Make intra-sentence code-switching the headline claim, not an afterthought.** Superwhisper's own docs concede Nova and Parakeet can't switch languages *within* a session at all, and even its capable models (Whisper-family/S1-Voice) need a manual "vocabulary hint" workaround to reliably detect a non-English language (superwhisper.com/docs/common-issues/language-detection). Nasar Flow's Singlish/Malay/Arabic mid-sentence mixing is a real, currently-unclaimed technical wedge — market it explicitly against this documented gap.
2. **[steal] Two-stage pipeline, independently toggle-able.** Adopt the STT-stage vs. cleanup-stage separation even while staying offline-by-default — it's good architecture regardless of where each stage runs, and it future-proofs an optional cloud cleanup tier without re-architecting.
3. **[steal, adapted] Publish Nasar Flow's own "what our AI cleanup will never do" list, headlining dialect preservation.** Borrow Superwhisper's S1-mini non-goals framing but make it the primary trust pitch, not a footnote: "Nasar Flow will never translate your Singlish into standard English, never flatten 'lah/lor/meh' particles, never romanize an Arabic-script choice you made."
4. **[beat] Ship a real spoken voice-command grammar, not just keyboard/mouse control.** Superwhisper's only "voice command" surface is Super Mode's selected-text formatting commands ("make this uppercase") — there's no spoken "delete that / new paragraph / undo." A trilingual command set (English/Malay/Arabic equivalents) would be a genuine differentiator no competitor here ships.
5. **[steal, adapt carefully] Whole-word, case-preserving, non-AI Replacements**, but extend "whole word" boundary logic to handle Jawi/Arabic script and Singlish contractions/particles as first-class targets — Latin-script "whole word" assumptions may not map cleanly onto Arabic script, so this needs its own testing before porting verbatim.
6. **[beat] Default to zero local audio retention, and say so loudly.** Superwhisper's actual default writes audio to disk with no obvious opt-out for non-Enterprise users, and reportedly stores cloud API keys in plaintext (getroutines.ai/transparency/superwhisper) — a real marketing/reality gap. Nasar Flow, as an offline-first app, should default to "nothing retained," encrypt anything it does keep, and market that contrast directly.
7. **[steal] Expose a History-tab-style debug view showing raw transcription vs. final output side by side**, so users (and support) can localize whether an error came from ASR or from cleanup — directly undercuts the "no easy way to catch errors" complaint reviewers make about Superwhisper (which actually already has this feature, but reviewers don't seem to know about it — Nasar Flow should make it more discoverable, not just present).
8. **[beat] Build a code-switched benchmark and publish it**, the way Superwhisper published WER numbers on 8 generic datasets + LibriSpeech for S1-Voice (superwhisper.com/blog/s1). No generic multilingual WER benchmark captures Singlish/Malay/Arabic code-switching accuracy — publishing one would be a defensible, hard-to-copy proof point.
9. **[beat] Handle filler-word removal with dialect awareness.** Superwhisper's Silence Removal/filler-stripping is tuned for English disfluency patterns. Nasar Flow must NOT treat Singlish discourse particles ("lah," "leh," "meh," "lor") as filler to be stripped — they're grammatical, not disfluent — so this is an area to explicitly do differently, not copy.
10. **[steal] Native, single-flow mobile activation.** Superwhisper's iOS activation still depends on a companion Mac/Windows app (QR code or license-URL pairing) — a bolt-on flow, not mobile-first (superwhisper.com/docs/get-started/activate-ios). Nasar Flow's keyboard extension should support full first-run activation from the phone alone, and market "no desktop app required" to the many Singlish/Malay/Arabic-speaking users who are Android/iOS-primary with no Mac at all.
11. **[steal] Be candid in docs about platform-vendor breakage, with the bug ID.** When iOS/Android platform changes break keyboard-extension behavior (they will), follow Superwhisper's playbook: name the OS version, name the exact behavior lost, file and cite the platform bug ID, and tell users how to add pressure — this converts "app is broken" 1-star reviews into "they're on it" goodwill.
